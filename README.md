# neotalk-sdk-stub

NeoTalk 앱(neotalk-apple, neotalk-android) 빌드용 **Stub SDK** 입니다.

- 실제 SDK 와 같은 API 모양(타입, 함수 서명)만 들어 있고 **구현은 없습니다.** 모든 호출은 "연결 안 됨" 오류나 빈 값을 돌려줍니다.
- 앱을 컴파일하고 UI 를 개발하는 용도입니다. 실서버에 접속하려면 Dev SDK 가 필요합니다.
- 파일은 [Releases](../../releases) 에 있습니다: `NeoTalkSDK-<버전>-<apple|android>-stub.zip`
